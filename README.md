# Total-Hospital-Insights-Admissions-Performance-and-Outcomes
Total Hospital Insights: a 4-page Power BI dashboard analysing 20,000 hospital admissions across 8 hospitals (2022-2025). Covers admission trends, patient demographics, hospital and insurer performance with a location map, and clinical outcomes, readmissions and billing. Built with Power BI, Power Query and DAX.

A 4-page Power BI dashboard that gives a complete view of hospital operations
using 20,000 patient admissions across 8 hospitals (2022 to 2025).

## Dashboard pages
1. **Hospital Admissions Overview:** KPIs, admission trends and categories
2. **Patient Demographics and Health Conditions:** age, gender and top conditions
3. **Hospital, Doctor and Insurance Performance:** map, hospital and doctor comparison, insurer share
4. **Clinical Outcomes and Cost Insights:** outcomes, readmissions and billing

## Tools used
Power BI, DAX, Power Query

## Dataset
Synthetic hospital admissions data (20,000 rows, 18 columns) plus a hospital
locations table used for the map.

## Files
- `Total_Hospital_Insights.pbix`: Power BI report
- `hospital_admissions_patient_analytics.csv`: admissions data
- `hospital_locations.csv`: hospital location data
- `screenshots/`: images of each dashboard page
